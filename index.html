06 / THE HONEST PART

Physics-inspired.
Evidence-first.

Real neuromorphic tissues use aqueous droplets, lipid membranes and voltage-gated ion channels. This sandbox uses normalized voltage, a membrane-polarization state and a smooth gate that changes inter-droplet conductance. Parameters are deliberately not presented as measured physical units.

Our experimental question: how does graph connectivity affect fading memory under identical stimulation and readout? The pulse-and-release assay measures downstream RMS in arbitrary units; it is not a physical memory timescale. Repeated seeded inputs are not independent experimental replicates, and standard deviations are not confidence intervals. Results are simulation-specific. The “Nested motif” topology is a speculative architectural comparison, not proof of Nested Bubble Gear or any physical theory.

# AquaPhi · The Wetware Observatory

**Where Matter Meets Memory.**

AquaPhi is an original, open-source, physics-inspired sandbox for exploring aqueous-droplet network computation and fading memory. It is a **toy simulation**, not a calibrated physical model or evidence of NBG.

The interactive laboratory is being prepared on a feature branch. See pull requests for the first release.

Research inspiration: [Neuromorphic tissues (Science Advances, 2026)](https://doi.org/10.1126/sciadv.aed0971).
